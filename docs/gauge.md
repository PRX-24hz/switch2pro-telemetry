## 1. 读数语义

### 1.1 它不是电压

满电时仅 **≈3670–3728**，而一节充满的锂电应有 4.15–4.2 V。
整段充电只爬升约 **+190**（3,539 → 3,728）。因此：

- **不能**用通用锂电开路电压曲线换算百分比（`data/sw2_charge.csv` 的 `soc_percent` 列即早期错误产物，**已废弃**）；
- 它更像**被偏移/缩放的电压样量**：同一块电池，插拔前后可差 **66 个单位**（3,616 ↔ 3,682）；
- 真实换算需要独立电压参照（万用表 / 功率计），本仓库没有。

### 1.2 维持期它跟着斩波摆动

60 秒 / 15,001 帧，按"跳变后第 k 帧"统计：

| 跳变后第 k 帧 | → `0x24` | → `0x00` |
|---|---|---|
| 0 | 3,673 | 3,693 |
| 8 | 3,689 | 3,687 |
| 15 | 3,692 | 3,674 |
| 30 | 3,674 | 3,673 |

**读数与斩波同步摆动，振幅约 ±10，滞后状态 10~15 帧（40~60 ms）。**

⇒ **实现约束**：维持期单帧读数有 ±10 噪声，必须跨 ≥1 个斩波周期（≈350 ms）平均；
UI 建议至少 1 秒窗口，否则数字会以 2.9 Hz 抖动。

### 1.3 禁止用途

- ❌ 跨插拔比较电量（差 66 个单位）
- ❌ 单帧读数当电压（±10 斩波噪声）
- ❌ 用锂电曲线换算百分比
- ❌ 把 `0x00`/`0x24` 的均值差当作固定偏移做校正（符号会翻转）
